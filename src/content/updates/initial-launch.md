We're excited to announce that the CodeCrew Software Inc. website is officially live!

Built from the ground up with **Astro 5**, **Vue 3**, and **Tailwind CSS 4**, the site reflects our philosophy: ship fast, ship right, and keep things lean.

## What's on the site

- **Services overview** — learn what we build and how we work
- **Our Edge** — understand what makes CodeCrew different
- **Blog** — thoughts on software development, AI, and building great products
- **Contact form** — reach out directly from the site

## Technical highlights

- Zero JavaScript shipped on static pages (Astro's island architecture)
- CSS-first animations for silky 60fps motion
- GSAP ScrollTrigger loaded only when needed via Vue islands
- Self-hosted fonts for privacy and performance
- Deployed automatically via GitHub Actions to GitHub Pages
